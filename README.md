# AnonHelper

AnonHelper port for the Shared runtime. Workspace location: `Mods/AnonHelper/`.

Projects:

- `Celeste.Mods.AnonHelper.csproj`

Repository dependencies: **Shared**. Prepare Shared resources using the [Tools README][tools-readme], then build the main project:

```powershell
dotnet build ./Mods/AnonHelper/Celeste.Mods.AnonHelper.csproj -c Release
```
